# InduSpect AI 隱私權政策（草稿）

> **狀態：草稿** — 上架 Google Play 前需完成：①法律審閱 ②填入正式聯絡方式 ③發布到公開 URL（Play 商店資料的「隱私權政策」欄位需要可公開存取的網址，可用 GitHub Pages）。
> 最後更新：2026-08-31

## 一、我們是誰

InduSpect AI（以下稱「本應用程式」）由國立勤益科技大學 doflab 研究團隊開發，是一款工業設備智慧巡檢工具。

## 二、我們處理哪些資料

| 資料類型 | 來源 | 用途 | 儲存位置 |
|---------|------|------|---------|
| 設備照片 | 使用者拍攝/選取 | AI 辨識設備狀態與儀表讀值 | 裝置本機；分析時傳送至 Google Gemini API |
| 位置資訊（GPS） | 裝置定位（經使用者授權） | 標記檢測地點，作為到場稽核佐證 | 裝置本機（SQLite） |
| 檢測紀錄（表單內容、AI 分析結果、法規判定） | 使用流程產生 | 檢測紀錄保存、報告產生 | 裝置本機（SQLite） |
| 量測讀數 | AI 辨識結果 | 送至後端伺服器進行法規標準判定 | 後端不保存（即時處理即回傳） |
| Gemini API Key | 使用者自行輸入 | 呼叫 Google Gemini API | 裝置本機 |

本應用程式**沒有帳號系統**，不收集姓名、電子郵件、電話等個人識別資訊；亦不含任何廣告或第三方追蹤 SDK。

## 三、資料如何流動

1. **離線優先**：拍照、填表、紀錄保存皆在裝置本機完成；沒有網路也能作業。
2. **AI 分析**：按下分析時，照片會透過您提供的 API Key 傳送至 **Google Gemini API** 處理。Google 對 API 資料的使用規範以其官方條款為準（付費層級的資料不用於模型訓練；詳見 [Gemini API 服務條款](https://ai.google.dev/gemini-api/terms)）。
3. **法規判定**：AI 辨識出的數值讀數（不含照片）會傳送至本團隊的後端伺服器比對法規標準，處理完即回傳，後端不留存。
4. **分享**：檢測報告與回填表單**只在您主動點擊「分享」時**離開裝置，經由您選擇的管道（Email、通訊軟體等）送出。

## 四、Android 權限用途

| 權限 | 用途 |
|------|------|
| 相機（CAMERA） | 拍攝設備照片 |
| 精確/概略位置（ACCESS_FINE/COARSE_LOCATION） | 檢測紀錄的 GPS 標記（僅在建立檢測時一次性定位，不做背景追蹤） |
| 網路（INTERNET） | AI 分析與法規判定 |
| 儲存/媒體 | 讀取圖庫照片、儲存匯出文件 |

所有權限均可拒絕；拒絕後對應功能降級（例如拒絕定位則紀錄不含地點），核心流程仍可使用。

## 五、資料保存與刪除

- 所有檢測資料保存在**您的裝置**，我們無法存取。
- 刪除方式：在「歷史紀錄」逐筆刪除，或於系統設定中清除本應用程式資料/解除安裝（將移除全部本機資料）。
- 傳送至 Gemini API 的內容依 Google 的保存政策處理；後端判定服務不保存請求內容。

## 六、兒童隱私

本應用程式為工業用途，不以未滿 13 歲兒童為對象，也不會蓄意收集其資料。

## 附錄：Google Play「資料安全」表單對照（填表用，非政策本文）

|-----------|------|
| 是否收集或分享使用者資料？ | 收集：照片（App 功能）、大約/精確位置（App 功能）。不分享給第三方（傳送至 Gemini API 屬服務供應商處理） |
| 資料是否加密傳輸？ | 是（HTTPS/TLS） |
| 使用者可否要求刪除資料？ | 資料存於裝置端，使用者可自行刪除 |
| 位置 | 收集・精確位置・非必要（可拒絕）・App 功能・不分享 |
| 相片和影片 | 收集・App 功能・傳送至 AI 服務供應商處理・不用於廣告 |
| 個人識別資訊 | 不收集 |
