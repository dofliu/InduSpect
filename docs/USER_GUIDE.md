# InduSpect AI 使用手冊

> 給現場使用者的操作說明。系統設計理念與技術架構看 [`../README.md`](../README.md)，
> 開發相關看 [`../CLAUDE.md`](../CLAUDE.md) 與 [`../flutter_app/DEVELOPMENT.md`](../flutter_app/DEVELOPMENT.md)。

App 主頁有三個入口：

| 入口 | 用途 | 資料跟著誰走 |
|---|---|---|
| **開始檢測** | 定檢表 pipeline：上傳表單 → 拍照 → AI 分析 → 自動回填 → 報告 | 跟著**一張表單** |
| **歷史紀錄** | 過往定檢紀錄，可搜尋、改標題、重新匯出與分享 | 同上 |
| **風機葉片檢測** | 葉片地面目視篩檢：選風機 → 引導拍攝 → 演算法量測 → 人工確認 → 報告 | 跟著**一台風機** |

前兩個是定檢主線，第三個是獨立的平行流程，兩者不共用資料也不共用演算法。

---

## 1. 開始檢測（定檢表，4 步驟）

### 步驟 1 — 上傳定檢表

選客戶原本的 Excel / Word 檔，或直接拍紙本。系統辨識表單結構，產生欄位對應與拍照任務清單。

後端不可用時自動改用本機解析。此時**匯出可能無法回填原始格式**，畫面上會明確提示。

### 步驟 2 — 逐項拍照檢測

可以按「一鍵自動檢測」批次跑完，也可以逐項拍。每張照片會走這條路：

1. **品質閘門**（純本機）：偵測模糊、過曝、欠曝、錶面反光。不合格會當場提示重拍，並說明怎麼補救。
2. **連線探測**：廠區常見「連上 AP 但沒有 uplink」，系統會先探一次網路是不是真的通。不通就直接走離線路徑，不空等逾時。
3. **聯網**：Gemini 分析，回傳設備類型、讀值、狀況評估、是否異常。
4. **離線**：裝置端 OCR 抽數位錶與銘牌的讀值。
5. **判定**：讀值進判定引擎，自動帶出合格／不合格／警告與法規依據。**這一步不需要網路。**

### 步驟 3 — 預覽確認

所有欄位都可以改。AI 判過的項目會標示來源（雲端精判 / 離線 OCR / 本地判定），**人工修改會覆蓋 AI 結果**。

### 步驟 4 — 產生報告

自動匯出回填後的定檢表與 AI 總結報告。完成頁還可以：

- 匯出**申報用 PDF**（含判定統計、逐項法規依據與單位換算、AI 總結、照片附件）
- 分享給客戶

## 2. 歷史紀錄

依 GPS 位置與時間列出過往檢測。可以改標題、搜尋、重新匯出 PDF、重新分享。
列表一次載 30 筆，捲到底再載下一頁。

## 3. 風機葉片檢測（5 步驟）

### 步驟 1 — 選風機

葉片檢測跟著**一台風機**累積紀錄，不是跟著一張表單。選同一台，下次到場才比對得起來。
資產資料可填輪轂高度與轉子直徑：系統據此提示站位距離（**水平 3–4 倍輪轂高、站在轉子軸線上**），並用照片焦距估相機站位、補償正視照的透視假訊號；沒填就只有 px、正視照的葉尖偏移會標「含透視分量」。

### 步驟 2 — 引導拍攝

畫面給一份格位清單：正視全機、側視全機、每片葉片的根／中／尖三段。每個格位會顯示

- **上次同格位的照片**（對照取景）
- **到上次拍攝點的 GPS 距離**（兩次的取景要接近，比對才有意義）

拍攝用**系統相機**（分區段照要用 5x 光學長焦），照片**原尺寸保存不壓縮**。
拍完立刻判定品質：讀不到檔或整張過暗會擋下，其餘只提醒。

也可以附加一段**轉動影片**（目前只有 Android 能抽幀）。**沒有音軌的影片解不了**——
抽幀的時刻由音軌決定，摘要會明說。

### 步驟 3 — 演算法分析

數值由演算法算，AI 只判斷「這是缺陷還是正常結構」。主判據是**同一張照片內的互比**
（前緣粗糙度 ÷ 後緣粗糙度、三片剪影互比），所以不需要絕對尺度校準。

### 步驟 4 — 人工確認

逐筆確認或駁回，可加備註。**沒有人簽過的發現不具效力。**

### 步驟 5 — 報告

PDF 報告。**不下「合格」判定**，並明寫這次跑了哪一層、沒跑哪一層。

## 4. 離線時會發生什麼

| 動作 | 沒有網路時 |
|---|---|
| 讀值 | 走裝置端 OCR（數位錶、銘牌）；指針錶讀不到，保留手動填寫 |
| **法規判定** | **照常運作**——判定引擎在裝置上，56 條標準全部內嵌 |
| 拍照品質閘門 | 照常運作，純本機 |
| PDF 報告 | 照常產生，純 Dart 離線 |
| 原格式回填 | 不可用，降級匯出 JSON 摘要（畫面會提示） |
| **分享／重新分享** | 進**離線佇列**，連線後自動送出 |
| **匯出（存檔）** | **照常開分享面板**——「儲存到檔案」與 AirDrop 離線可用，擋掉等於拿掉功能 |
| 「待判定」狀態 | 連線後自動重新判定（只重跑還卡在待判定的，不會無聲換掉你看過的判定） |

## 5. 常見問題

**照片一直被擋下來重拍。**
閘門會說明是哪一項不過（模糊／過曝／欠曝／反光）。反光最常見的解法是換一個角度，
不要正對錶面；模糊多半是對焦沒鎖定或手震。

**為什麼分享按下去沒反應？**
沒有網路時分享會進佇列，連線後自動送出。要當下拿到檔案請用「匯出」，那個離線可用。

**葉片報告為什麼不寫「合格」？**
手機地面拍攝屬 Level 1 篩檢，「未檢出異常」不等於「整支葉片都查過了」。
系統只報「未發現」，不報「合格」。

**葉片檢測第二次拍，跟上次對不起來。**
檢查引導拍攝畫面上的 GPS 距離提示，站位要盡量接近上次；正視與側視是**不同的站位**，
每張全機照各自記錄自己的位置。

**判定結果和我的認知不同。**
判定依據會寫在報告上（法規條文 + 單位換算過程）。所有欄位都可以人工覆蓋，
人工修改會覆蓋 AI 與引擎的結果。

## 6. 主頁上沒有的東西

主頁只有三個入口：定檢表檢測、歷史紀錄、風機葉片。程式裡另有「快速分析、範本系統、雲端同步」等
舊流程的畫面，**沒有任何路徑能到達**——它們是待移除的死碼，不是隱藏功能，使用手冊不涵蓋。
設定頁可到達的「RAG 管理」目前也**不參與任何檢測流程**。詳見
[`PROJECT_ASSESSMENT.md`](PROJECT_ASSESSMENT.md) §3。
