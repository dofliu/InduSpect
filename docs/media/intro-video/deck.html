02
解法

一支 App 走完全程
交付物仍是客戶原本的檔案

  • 兩個入口就好：開始檢測、歷史紀錄——現場不需要教學
  • 離線優先：拍照、判定、暫存全程可斷網作業
  • GPS + 時間戳：自動附上到場稽核軌跡
  • 零導入成本：不改客戶的表單習慣，回填原始 Excel / Word

04
差異化 ① 法規判定

56 條台灣法規標準，自動判定合格與否

判定前先把讀值換算成法規單位——這是安全等級的防呆。
實例 絕緣電阻讀值 500 kΩ　·　法規標準 ≥ 1.0 MΩ
未換算 500 ≥ 1.0 → 誤判「合格」　← 差一個數量級，安全隱患直接放行
換算後 500 kΩ = 0.5 MΩ，0.5 < 1.0 → 正確判「不合格」
法規依據自動附上：屋內線路裝置規則 第59條　·　覆蓋電氣 / 消防 / 機械 / 壓力四大類
05
差異化 ② 離線能力

斷網也能判定——三層 AI 架構

Tier 0離線 · 全機型
法規判定引擎（純規則，零 AI）56 條標準內嵌 App；單位換算 + 條文引用。判定零延遲、零 token 成本
Tier 1a離線 · 全機型
裝置端 OCR 讀值ML Kit 離線辨識數位錶與銘牌 → 直接進 Tier 0 判定
Tier 2聯網
雲端 Gemini 精判 + 摘要報告指針錶與複雜異常；恢復網路後自動覆核離線初判
標準資料單一來源：後端 Python 為編輯來源 → 匯出 JSON 內嵌 App，CI 守門確保兩端永不漂移
06
工程韌性

模型可換，金鑰在你手上

  • GA 穩定版模型：preview 版模型下架不會讓 App 全面故障
  • 三層覆寫：參數 > .env > 內建預設，換模型免改版

  • 資安敏感場域：後端可整套部署到廠內網（禁網亦可用）
